
🔍 Wireshark: Packet Operations — TryHackMe SOC Level 1

📌 Project Overview

As part of my Cybersecurity learning journey, I completed practical exercises in Wireshark: Packet Operations on TryHackMe. This lab focuses on network traffic analysis, packet inspection, protocol identification, and understanding how network communications work.

The objective was to develop practical skills in analyzing network traffic and identifying important information that can support Security Operations Center (SOC) investigations.

🎯 Learning Objectives

- Understand the fundamentals of packet analysis.
- Analyze network traffic using Wireshark.
- Identify source and destination IP addresses.
- Examine TCP, UDP, DNS, and HTTP traffic.
- Understand TCP communication, including SYN and ACK flags.
- Analyze packet lengths, ports, and communication patterns.
- Use Wireshark statistics to identify active network endpoints.
- Develop foundational skills for SOC Level 1 investigations.

🛠️ Tools & Technologies

- Wireshark — Network protocol analyzer.
- TryHackMe — Cybersecurity training platform.
- PCAP files — Captured network traffic for analysis.
- TCP/IP Networking — Core networking protocols and concepts.

🔬 Practical Exercises

1. Network Endpoint Analysis

Used Wireshark's Endpoints statistics to examine communicating IP addresses and review packet counts, transferred bytes, and available geographical or network ownership information.

2. Packet Inspection

Inspected individual packets to understand their source and destination addresses, protocols, packet lengths, and other network-layer details.

3. TCP Traffic Analysis

Examined TCP communication patterns, including SYN, ACK, and PSH flags, to understand connection establishment and data transmission.

4. HTTP and DNS Traffic

Identified HTTP requests and DNS queries within the captured traffic to understand how clients request web resources and resolve domain names.

5. Network Traffic Statistics

Used Wireshark's statistics features to summarize captured traffic and identify endpoints generating network activity.
